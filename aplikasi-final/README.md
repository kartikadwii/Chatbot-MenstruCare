# 🌸 MenstruCare

**Kenali Siklusmu, Pahami Tubuhmu.**

MenstruCare merupakan chatbot edukasi menstruasi berbasis web yang
dikembangkan menggunakan Python dan Flask. Aplikasi ini membantu
pengguna memperoleh informasi seputar menstruasi melalui interaksi
berbasis teks.

## Fitur Utama

1. Chatbot edukasi menstruasi.
2. Pengenalan intent menggunakan pencocokan teks.
3. Normalisasi kata dan preprocessing.
4. Riwayat percakapan menggunakan SQLite.
5. Dashboard statistik admin.
6. Evaluasi performa chatbot menggunakan data CSV.
7. Pengujian otomatis menggunakan Pytest.
8. Tampilan responsif untuk desktop dan perangkat mobile.

## Teknologi

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- JSON
- CSV
- Pytest
